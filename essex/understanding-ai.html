Machine Learning for Credit Default Prediction

Experimental report and notebook

This experiment tests whether machine learning can support credit decisions for a FinTech lender. It uses 30,000 records from the UCI Default of Credit Card Clients dataset. Logistic regression, a decision tree and a random forest were compared across the trade-off between interpretability and accuracy. The report sets the results against the EU AI Act requirement that credit decisions remain explainable.
