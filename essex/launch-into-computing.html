This module covered the foundations of computing: algorithms, programming languages, software development methodologies, data, security and IT governance. The artefacts below combine working code with written analysis.

Programming and algorithms

Sorting Algorithm Performance

Code and report

Bubble sort and quicksort were implemented in Python and tested with pytest before the performance runs. Both were timed on datasets from 100 to 100,000 elements. Bubble sort needed over 600 seconds for the largest dataset, while quicksort finished in under one second. The report links this result to test automation and continuous integration, where slow code leads teams to skip their test suites.

Code Exploration and Language Comparison

End of module assignment · Parts A1 and A2

Two name-cleaning scripts, one in Python and one in JavaScript, were run and debugged. Both returned eight names instead of five because neither normalised the input before removing duplicates. The scripts were corrected and covered by unit tests in each language. A comparison report then evaluates Python and JavaScript across programming model, readability, error handling and suitability for current computing tasks.

Data and machine learning

Stack Overflow Developer Survey Analysis

Code and reflection

This Python project analyses the 2024 and 2025 Stack Overflow Developer Surveys to compare CI/CD tool adoption by organisation size and developer role. It is structured as loader, analysis and visualisation modules, each with its own tests. A short reflection evaluates whether a relational or a document database suits the data. It concludes that SQL remains the stronger choice despite one multi-value column.

F1 DNF Prediction

Machine learning model and evaluation

A Random Forest classifier predicts whether a Formula 1 driver will fail to finish a race. It was trained on 14,086 race entries from 1990 onwards. The data was imbalanced, with 32% retirements, so the evaluation focuses on precision and recall rather than accuracy alone. Historical reliability rates were computed without data leakage. The analysis also covers ethical risks, such as encoding past team performance into predictions.

CI/CD Pipeline Compromise: Threat Assessment and Mitigation Plan

Scenario-based report

A fictional software company discovers malicious code injected through its build pipeline. The report traces the breach to three weaknesses: dependency confusion, plaintext deployment secrets and missing build monitoring. It proposes controls at three levels, including pinned and verified dependencies, signed artefacts, the SLSA framework and least-privilege secrets management.
